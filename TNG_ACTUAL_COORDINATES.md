### Field Placement Algorithm:
1. **Text Fields:** `drawText(value, x, y, { size: 9, font: helvetica })`
2. **Checkboxes:** Draw small box at (x, y), place checkmark if value === true
3. **Radio Buttons:** Draw circle at (x, y), fill if value === true
4. **Textarea:** Use `drawText()` with word wrapping within (width, height) bounds
5. **Signature Canvas:** Convert canvas PNG to image, embed at (x, y) with size (width, height)
6. **Date Fields:** Format as "DD/MM/YYYY" before placing
